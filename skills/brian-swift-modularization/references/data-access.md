# 데이터와 외부 접근

Entity, 서비스 API, 로컬 저장소의 위치를 결정할 때 읽는다. 아래 규칙은 사용자가 승인한 개인 컨벤션이며 TCA 비종속 구조 규칙이다. 구체적인 DB 엔진, 네트워킹 라이브러리, 인증·캐시 정책은 정하지 않았다.

## 공용 데이터

- **규칙:** Feature와 Client가 공유하는 앱 데이터는 Shared 패키지의 단일 Entities 타깃에 모은다.
- **분류:** 개인 컨벤션
- **강도:** 기본값
- **적용 조건:** 모델을 추가하거나 공유 위치로 이동할 때
- **Do:** User·Product 같은 공용 타입을 Entities에 두고 필요하면 업무 영역별 폴더로 구분한다. 화면 전용 데이터는 Feature 내부에, 서버 요청·응답 DTO는 해당 Client 내부에 둔다.
- **Don't:** 타입이나 업무 영역마다 Entity 패키지·타깃을 만들거나, 모든 화면 상태와 서버 DTO를 Entities에 모으지 않는다.
- **이유와 예외:** 예상 데이터 규모에 맞춰 관리 단위를 줄인다. 의미 있는 차이 없이 DTO와 Entity를 기계적으로 복제하지 않는다. 서버 전용 형식과 앱 데이터가 다르면 Client 내부에서 변환한다.
- **근거:** 사용자의 공용 데이터 단일 Entities 구성 승인 및 API 배치 승인
- **검토 버전:** TCA 비종속 구조 규칙

## 서버 API

- **규칙:** 공통 HTTP 전송 기능은 Shared의 Networking에 두고, 서비스별 API와 실제 구현 연결은 해당 Client 타깃 내부에 둔다.
- **분류:** 개인 컨벤션
- **강도:** 기본값
- **적용 조건:** 서버 API를 추가하거나 통신 코드를 추출할 때
- **Do:** Networking은 공통 요청 실행·HTTP 상태 확인·인코딩·디코딩을 담당한다. Client 내부의 API 폴더에는 필요한 Endpoint·Request·Response를 둔다. Client 선언과 실제 구현은 같은 타깃에 둔다. Feature가 사용하는 결과는 앱 데이터 형태로 반환한다.
- **Don't:** API마다 모듈을 만들거나 Interface·Implementation을 분리하지 않는다. 단순 호출에도 Router·Repository·Service 계층이나 빈 Request 파일을 일괄 생성하지 않는다. Networking이 상위 Client에 의존하게 하지 않는다.
- **이유와 예외:** 서비스 변경은 해당 Client 안에서 처리하고 공통 전송 정책만 Networking으로 모은다. Client 파일명과 의존성 등록 방식은 이 스킬에서 정하지 않는다. 요청 구성이 간단하면 Endpoint 파일을 생략할 수 있다. 인증 정보가 필요하면 기존 방식에 맞게 전달받으며 토큰 저장·갱신 정책을 임의로 정하지 않는다.
- **근거:** 사용자의 Client 내부 API 및 공통 Networking 배치 승인
- **검토 버전:** TCA 비종속 배치 규칙. Client 선언·등록의 API 호환성은 대상 프로젝트에서 확인한다.

## 선택적인 로컬 저장소

- **규칙:** 로컬 DB가 실제로 필요할 때 Shared에 LocalDatabase 타깃을 추가하고, 사용하는 Client가 직접 의존한다.
- **분류:** 개인 컨벤션
- **강도:** 조건부
- **적용 조건:** DB 접근을 구현하거나 공통 저장소 기능을 추출할 때
- **Do:** 연결·트랜잭션·마이그레이션 등 저장소 기반은 LocalDatabase에 둔다. 상품 조회·저장과 서버·로컬 데이터 조합, 캐시 정책은 해당 Client에서 담당한다.
- **Don't:** LocalDatabase를 ClientCore의 필수 의존성으로 추가하거나 LocalDatabase가 ClientCore를 참조하게 하지 않는다. DB가 필요하지 않은 프로젝트에 빈 타깃을 생성하지 않는다.
- **이유와 예외:** 필요한 Client만 저장소 기능을 사용한다. 저장 스키마의 세부 소유권과 DB 엔진은 대상 프로젝트에 맞춰 정하며, 기존 근거 없이 특정 엔진을 선택하거나 마이그레이션 정책을 만들어 내지 않는다.
- **근거:** 사용자의 필요한 Client에서 LocalDatabase에 직접 의존하는 방식 승인 및 선택 기능 미구현 허용 결정
- **검토 버전:** TCA 비종속 구조 규칙
